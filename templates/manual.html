1. Introducción

Este sistema implementa las principales herramientas de Control Estadístico de Procesos (CEP / CEC) aplicadas al monitoreo de la calidad de frutas, hortalizas y plantas medicinales.

Permite a un analista o equipo de calidad:

  • Registrar muestras de un proceso con su trazabilidad completa.
  • Aplicar pruebas estadísticas para verificar normalidad de los datos.
  • Construir gráficos de control (X̄-R, X̄-S, p, np, c, u) que detectan automáticamente cuándo el proceso se sale de control.
  • Calcular índices de capacidad del proceso (Cp, Cpk, Pp, Ppk).
  • Identificar las causas principales de no conformidad con un diagrama de Pareto.
  • Importar datos desde Excel y exportar reportes completos.

El sistema funciona como aplicación web; basta con un navegador moderno. Los datos se almacenan en una base de datos PostgreSQL (Supabase) y persisten entre sesiones.

2. Requisitos y acceso

Para usar la aplicación

  • Navegador moderno: Chrome 100+, Firefox 100+, Safari 15+, Edge 100+.
  • Conexión a internet (la app está desplegada en Vercel).
  • Para subir Excel: archivos con extensión .xlsx, máximo 5 MB.

Para uso local / desarrollo

  • Python 3.9 o superior.
  • Instalar dependencias: pip install -r requirements.txt.
  • Arrancar: python api/index.py --port 5050 --debug.
  • Opcional: archivo .env con DATABASE_URL para conectar a Supabase.

Acceso a la versión desplegada

Abre la URL pública del proyecto en Vercel (te la entrega el equipo). Comparte el enlace con cualquier persona que necesite registrar o consultar datos.

4. Flujo de trabajo recomendado

Paso 1. Define qué quieres controlar: una variable continua (peso, pH, °Brix) o un atributo (defectos, manchas, frutos podridos).
Paso 2. Determina el tamaño de subgrupo (n). Para variables es típicamente 4 ó 5; para atributos depende de la frecuencia esperada de defectos.
Paso 3. Toma al menos 25 subgrupos de manera secuencial. Es el mínimo recomendado por la literatura (Montgomery).
Paso 4. Registra los datos en la app — manualmente o subiendo un Excel preformateado.
Paso 5. Analiza el gráfico de control y la lista de reglas de Nelson. Si hay puntos fuera o patrones, investiga las causas asignables.
Paso 6. Si el proceso está estable, calcula la capacidad (Cp/Cpk). Esto te dice si cumple las especificaciones técnicas.
Paso 7. Exporta el reporte a Excel para archivar o compartir.

6. Control por variables (datos continuos)

Para mediciones numéricas (peso, dimensiones, contenido químico, etc.).

Gráfico X̄-R n entre 2 y 9

Monitorea la media y el rango de cada subgrupo. Es el gráfico más utilizado por su simplicidad y robustez con muestras pequeñas.

UCLX̄ = X̄̄ + A2 · R̄  |  LCLX̄ = X̄̄ − A2 · R̄
UCLR = D4 · R̄  |  LCLR = D3 · R̄
σ̂ = R̄ / d2

Gráfico X̄-S n ≥ 10

Similar al X̄-R pero usa la desviación estándar S en lugar del rango. Más eficiente estadísticamente para subgrupos grandes.

UCLX̄ = X̄̄ + A3 · S̄  |  LCLX̄ = X̄̄ − A3 · S̄
UCLS = B4 · S̄  |  LCLS = B3 · S̄
σ̂ = S̄ / c4

Las constantes A2, A3, D3, D4, B3, B4, d2, c4 dependen del tamaño de subgrupo y están implementadas en el código siguiendo Montgomery (Statistical Quality Control, 7th ed.) para n entre 2 y 25.

7. Control por atributos (datos discretos)

Para conteos: "frutos defectuosos", "número de manchas", "presencia de plagas".

Gráfico p n variable

Mide la proporción de unidades defectuosas. Tolera tamaños de muestra que cambian entre subgrupos.

p̂i = di/ni  |  p̄ = Σd / Σn
UCL = p̄ + 3·√[ p̄(1−p̄)/ni ]  |  LCL = max(0, …)

Gráfico np n constante

Equivalente al gráfico p pero grafica directamente el número de defectuosos. Requiere que el tamaño de muestra sea siempre el mismo.

UCL = np̄ + 3·√[ np̄(1−p̄) ]  |  LCL = max(0, np̄ − 3·√[ np̄(1−p̄) ])

Gráfico c área constante

Cuenta defectos por unidad (no unidades defectuosas — un fruto puede tener varios defectos). Asume distribución Poisson.

UCL = c̄ + 3·√c̄  |  LCL = max(0, c̄ − 3·√c̄)

Gráfico u área variable

Similar al c pero permite que el "área de oportunidad" (kg de fruta, m² de campo, tamaño de lote) varíe.

ui = ci/ni  |  ū = Σc / Σn
UCL = ū + 3·√(ū/ni)  |  LCL = max(0, ū − 3·√(ū/ni))

8. Pruebas de normalidad

Los gráficos X̄-R y X̄-S y los índices de capacidad asumen que los datos siguen una distribución normal. Antes de interpretarlos, conviene verificar este supuesto.

Tres pruebas disponibles

PruebaCuándo usarn mínimoSensibilidad
Shapiro-WilkMuestras pequeñas-medianas3Muy alta, recomendada por defecto
Anderson-DarlingCualquier tamaño, énfasis en colas8Alta, especialmente en extremos
D'Agostino-PearsonMuestras grandes20Basada en asimetría y curtosis

Interpretación del p-valor

  • Si p > 0.05: no se rechaza la hipótesis nula → los datos son compatibles con una distribución normal.
  • Si p < 0.05: se rechaza la normalidad → los datos no son normales. Considera transformar (log, raíz cuadrada, Box-Cox) o usar métodos no paramétricos.

Apoyos visuales

  • Histograma con curva normal: si las barras se ajustan a la curva, los datos son aproximadamente normales.
  • Gráfico Q-Q: los puntos deben quedar cerca de la línea diagonal de referencia. Curvaturas indican asimetría o colas pesadas.

9. Capacidad del proceso

Una vez que el proceso está estable, el siguiente paso es saber si cumple con las especificaciones del producto. Aquí entran los índices de capacidad.

Cp = (USL − LSL) / (6·σwithin)
Cpk = min[ (USL − μ)/(3σ), (μ − LSL)/(3σ) ] usando σwithin
Pp = (USL − LSL) / (6·σoverall)
Ppk = idem Cpk pero con σoverall

Diferencia entre σwithin y σoverall

  • σwithin: variabilidad dentro de subgrupos (corto plazo). Estimada como R̄/d2 o S̄/c4.
  • σoverall: variabilidad total considerando todos los datos (corto + largo plazo). Estimada como desviación estándar muestral.

Tabla de interpretación de Cpk

Valor de CpkEstadoAcción
≥ 1.67Clase mundialMantener, considerar reducir control
1.33 – 1.67CapazMonitoreo de rutina
1.00 – 1.33AdecuadoControl estricto, mejorar
0.67 – 1.00Parcialmente capazPlan de mejora urgente
< 0.67IncapazDetener, rediseñar proceso

Cp vs Cpk

  • Cp mide el "potencial" del proceso (qué tan ancha es la dispersión comparada con las especificaciones), sin importar dónde está centrado.
  • Cpk mide el desempeño real teniendo en cuenta también el centrado. Cuando Cp > Cpk, el proceso no está centrado entre los límites.

10. Diagrama de Pareto

Basado en el principio 80/20 de Vilfredo Pareto: aproximadamente el 80% de los problemas provienen del 20% de las causas.

Cómo usarlo

  1. Ve a la sección Pareto.
  2. Agrega las categorías de defecto y su frecuencia observada en un periodo.
  3. Click en Generar Pareto.

Cómo leerlo

  • Las barras (azul) están ordenadas de mayor a menor frecuencia.
  • La línea naranja muestra el porcentaje acumulado.
  • La línea horizontal roja punteada marca el 80%.
  • Las categorías que están a la izquierda del cruce con esa línea son las "pocas vitales" — concentra tus esfuerzos de mejora ahí.

11. Reglas de Nelson

Lloyd S. Nelson (1984) propuso reglas adicionales para detectar patrones no aleatorios en los gráficos de control, más allá del simple "punto fuera de ±3σ". El sistema implementa 6 de las 8 reglas clásicas:

ReglaDescripciónIndica
11 punto más allá de ±3σCausa asignable inmediata
29 puntos consecutivos del mismo lado de la línea centralShift de la media
36 puntos consecutivos con tendencia creciente o decrecienteDeriva (drift) — herramienta gastándose, fatiga, etc.
414 puntos consecutivos alternando arriba/abajoMezcla de dos procesos / sistemático
52 de 3 puntos consecutivos más allá de ±2σ del mismo ladoShift incipiente
64 de 5 puntos consecutivos más allá de ±1σ del mismo ladoShift pequeño persistente

Las violaciones se muestran en la pestaña Reglas de Nelson dentro de cada estudio.

13. Dashboard y filtros

En la página de Inicio aparece:

  • Tarjetas de resumen: total de estudios, separados por tipo y estado del almacenamiento.
  • Tabla de Estudios anteriores con búsqueda y filtros:
    • Buscar: por nombre, producto, característica, analista o lote.
    • Tipo: filtra variables o atributos.
    • Gráfico: filtra por tipo de gráfico (xr, xs, p…).
    • Orden: fecha, nombre, producto.
  • Botones por estudio:
    • Abrir: ir a la página de análisis.
    • ⤓: descargar el reporte Excel directamente.
    • ×: eliminar el estudio (pide confirmación).

14. Cómo interpretar los resultados

Caso: proceso en control

  • Ningún punto fuera de los límites.
  • No hay violaciones a las reglas de Nelson (o son muy pocas).
  • Los puntos oscilan aleatoriamente alrededor de la línea central.
  • Si hay LSL/USL definidos: calcula Cpk.
    • Cpk ≥ 1.33 → el proceso cumple las especificaciones.
    • Cpk < 1.33 → ajusta centrado o reduce variabilidad.

Caso: proceso fuera de control

  1. No calcules capacidad todavía. Cp/Cpk solo tienen sentido cuando el proceso es estable.
  2. Identifica el primer punto que viola una regla.
  3. Investiga qué cambió en ese momento del proceso (cambio de operador, materia prima, equipo, ambiente).
  4. Aplica acciones correctivas, vuelve a muestrear y recalcula.

Caso: datos no normales

  • X̄-R y X̄-S son robustos a desviaciones leves; siguen siendo útiles.
  • Para no normalidad fuerte: transformar (log, raíz, Box-Cox) o cambiar a gráficos de cuantiles / no paramétricos.
  • La capacidad calculada bajo asunción de normalidad será imprecisa — repórtala con esa salvedad.

16. Glosario

Atributo
Característica de calidad que se evalúa como presencia/ausencia o conteo (defectos, manchas).
Capacidad del proceso
Aptitud de un proceso para producir dentro de los límites de especificación.
Causa asignable (especial)
Fuente identificable de variación no inherente al proceso. Ej: lote de materia prima distinto, falla de un equipo, cambio de operador.
Causa común (aleatoria)
Variación inherente al proceso, presente todo el tiempo. Solo se reduce rediseñando el sistema.
LSC / LIC (UCL / LCL)
Límites superior / inferior de control. Calculados como ±3σ desde la línea central.
LSL / USL
Lower / Upper Specification Limit. Límites del producto definidos por especificación técnica o normativa.
Proceso en control estadístico
Proceso cuya variabilidad proviene únicamente de causas comunes; es predecible estadísticamente.
Subgrupo
Conjunto de mediciones tomadas en condiciones lo más homogéneas posibles (mismo turno, mismo lote, mismo momento).
Variable
Característica medible numéricamente: peso, longitud, °Bx, pH.
