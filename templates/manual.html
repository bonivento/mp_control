Manual de usuario

Guía rápida para usar el sistema de Control Estadístico de Calidad aplicado a frutas, hortalizas y plantas medicinales.

1. Tipos de control

Variables continuas

Mediciones numéricas como peso (g), diámetro (cm), pH, °Brix, firmeza, humedad (%), etc.

  • X̄-R: subgrupos pequeños (n entre 2 y 9). Usa el rango como medida de variabilidad.
  • X̄-S: subgrupos grandes (n ≥ 10). Usa la desviación estándar (más eficiente).

Atributos (conteos)

Características clasificadas como conformes / no conformes (manchas, plagas, defectos visuales).

  • p: proporción de unidades defectuosas (tamaño de muestra variable).
  • np: número de unidades defectuosas (tamaño de muestra constante).
  • c: número de defectos por unidad (área de oportunidad constante).
  • u: defectos por unidad (área variable).

2. Flujo recomendado

  1. Crear nuevo estudio en Nuevo Estudio, completando trazabilidad (producto, característica, analista, lote, unidad).
  2. Seleccionar tipo de gráfico y, si aplica, definir límites de especificación (LSL/USL).
  3. Ingresar al menos 25 subgrupos (requisito del trabajo final).
  4. Guardar — el sistema calculará automáticamente:
    • Gráficos de control con LSC / LC / LIC
    • Detección de puntos fuera de control y reglas de Nelson
    • Pruebas de normalidad (variables)
    • Índices de capacidad Cp/Cpk/Pp/Ppk (variables con LSL/USL)
  5. Exportar el reporte completo a Excel.

3. Interpretación de Cp / Cpk

Valor de CpkInterpretación
≥ 1.67Proceso de clase mundial
1.33 – 1.67Proceso capaz
1.00 – 1.33Adecuado, requiere control estricto
0.67 – 1.00Parcialmente capaz, requiere mejoras
< 0.67Incapaz, acción inmediata

4. Reglas de Nelson para detección de patrones

  • Regla 1: 1 punto fuera de ±3σ
  • Regla 2: 9 puntos consecutivos del mismo lado de la línea central
  • Regla 3: 6 puntos consecutivos con tendencia (creciente o decreciente)
  • Regla 4: 14 puntos alternando arriba/abajo
  • Regla 5: 2 de 3 puntos consecutivos más allá de ±2σ del mismo lado
  • Regla 6: 4 de 5 puntos consecutivos más allá de ±1σ del mismo lado

5. Formato para pegar desde Excel

En las pantallas de registro puedes pegar datos copiados directamente desde Excel:

  • X̄-R / X̄-S: cada fila = un subgrupo, cada columna = una medición.
  • p, u: dos columnas — defectuosos / defectos y tamaño de muestra.
  • np, c: una sola columna con los conteos.

6. Limitaciones del entorno serverless

Vercel: el sistema usa SQLite, y en Vercel el filesystem es efímero. Los datos pueden perderse entre invocaciones. Para uso productivo se recomienda configurar una base de datos PostgreSQL (Neon, Supabase o Vercel Postgres) mediante la variable DATABASE_URL.
